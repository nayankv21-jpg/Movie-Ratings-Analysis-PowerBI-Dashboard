# Movie Ratings Analysis — Power BI

An interactive Power BI dashboard designed to analyze movie ratings, genres, votes, and other key movie-related metrics.

## Project Overview

This project uses Microsoft Power BI to transform movie data into an interactive and visually engaging dashboard.

The dashboard provides an overview of movie ratings, genre-wise performance, audience votes, and content distribution. Interactive filters allow users to explore the data and identify patterns across different movie categories.

## Objectives

- Analyze movie ratings and audience feedback
- Compare ratings across different genres
- Analyze the number of votes received by movies
- Identify patterns in movie performance
- Explore movie data using interactive filters
- Present insights through an interactive Power BI dashboard

## Dashboard Features

### Rating Analysis

- Distribution of movies across different rating categories
- Comparison of movie ratings
- Analysis of average ratings

### Genre Analysis

- Comparison of ratings across different genres
- Identification of genres with higher average ratings
- Exploration of movie performance by genre

### Audience Analysis

- Analysis of movie votes
- Comparison of audience engagement across movies
- Relationship between ratings and number of votes

### Interactive Filtering

The dashboard includes interactive filters that allow users to explore the data based on available movie categories and attributes.
